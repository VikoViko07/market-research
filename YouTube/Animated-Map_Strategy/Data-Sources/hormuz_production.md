## MUSIC SYSTEM

### Source — YouTube Audio Library
URL: studio.youtube.com → Content → Audio Library
License: YouTube Audio Library license
Commercial use: YES — free for monetized YouTube
Attribution: NOT required (but good practice)

### How to find the right tracks
1. Go to studio.youtube.com
2. Click Audio Library in left menu
3. Filter by: Genre → Ambient / Documentary
4. Filter by: Mood → Dark / Tense / Inspirational
5. Filter by: Duration → match your segment length
6. Download as MP3 → import to video editor

### Three-track music structure

**Track 1 — INTRO THEME (0:00–2:00)**
Mood: Minimal, tension building slowly
Style: Single instrument, sparse. Think: slow piano or single synth note held.
Why: matches the silence + one number aesthetic.
Search terms: "minimal tension" "documentary opener" "sparse atmospheric"
Volume: -18 dB (very quiet — almost subliminal)
Fade in: 3 seconds starting at 0:02

**Track 2 — MAIN THEME (2:00–8:00)**
Mood: Documentary, measured authority
Style: Orchestral or electronic documentary. Think: Wendover, Vox explainer energy.
Why: carries the information segments without competing with narration
Search terms: "documentary" "investigative" "corporate tension"
Volume: -20 dB during narration, -14 dB during data-only moments
Fade crossfade from Track 1: 4 seconds at 2:00

**Track 3 — ENDING THEME (8:00–10:00)**
Mood: Reflective, open-ended, slightly unresolved
Style: Minimalist, strings or piano. Ends without resolution.
Why: matches the open question ending — no answer, no triumph
Search terms: "reflective" "contemplative" "bittersweet"
Volume: -16 dB, fade out completely by 10:00
Fade crossfade from Track 2: 4 seconds at 8:00

### Music rules
```
NEVER: music louder than narration
NEVER: music with lyrics (competes with narrator)
NEVER: dramatic swells on data moments
       (data speaks for itself — music is background)
ALWAYS: fade music DOWN when narrator speaks a key number
        (even -3 dB more = number hits harder)
ALWAYS: music fully fades by last frame
        (open question needs silence at the end)
```

## ANIMATION PRINCIPLES

```
ONE NUMBER RULE: narrator speaks only ONE number per frame.
PAUSE RULE: 2–3 sec silence after every key number appears.
REVEAL RULE: tables build row by row with narration.
COMPLEMENT RULE: text on screen ≠ narrator words.
TRANSITION TYPES — full glossary:

  CUT — instant switch between clips. No smoothing.
         One frame ends, the next begins immediately.
         Duration: 0 sec.
         In editor: place two clips back to back,
         no effect applied.
         When to use: change of visualization type,
         high-energy moment, new idea starting.
         Example in this video: flow map → bar chart (3:15)

  FADE — current frame fades to black,
          then next frame appears from black.
          Duration: 0.5 sec.
          In editor: "Dip to Black" or
          "Cross Dissolve to Black".
          When to use: between major segments,
          topic change, breathing room for viewer.
          Example in this video: Intro → Geography (2:00),
          History → Bypass (6:00)

  DISSOLVE — current frame blends directly
              into the next frame without going to black.
              Duration: 0.8 sec.
              In editor: "Cross Dissolve" or "Morph Cut".
              When to use: within a segment when two
              frames are visually connected and the
              transition should feel smooth.
              Example in this video: map → flow map (2:45),
              b-roll → bar chart (6:50)

  — (dash) — no transition in this row.
              Current frame continues.
              Next element appears on top of
              the existing background.
```

```

Builds the argument in three layers.
```
