# Free, Trustworthy, and Licensable — Complete Reference

---

## How to Use This Document

Every source listed here meets three criteria:
1. **Free to access** — no paywall for the data you need
2. **Trustworthy** — cited by academic institutions, governments, or major media
3. **Safe to use** — CC0, public domain, government data, or open license

For each source: what data is available, license type, how to download, and which evergreen topics it serves.

---

## License Types — Quick Reference

| License | What it means | Can use in video? |
|---------|--------------|-------------------|
| **CC0** | Public domain — no restrictions whatsoever | Yes, no attribution needed |
| **CC BY** | Free to use, must credit the source | Yes, show source in video |
| **CC BY-SA** | Free to use, must credit, derivatives same license | Yes, show source |
| **Government / Public data** | Published by official government body | Yes, always cite |
| **Open Data** | Freely available, varies by terms | Check per source |
| **Proprietary** | Paid or restricted | No — or requires license |

**Practical rule for video:** Always show the source name on screen regardless of license. "Source: World Bank, 2024" protects you legally and builds viewer trust.

## The Three Sources Every Evergreen Channel Uses

If you only bookmark three sources, make it these:

**1. Our World in Data (ourworldindata.org)**
The single best starting point for any evergreen topic. CC BY license, data goes back centuries on many indicators, charts are already designed and downloadable, team at Oxford constantly adds new datasets. Kurzgesagt has an official collaboration with OWID.

**2. World Bank Open Data (data.worldbank.org)**
The authoritative source for country-level economic data. CC BY license, covers 200+ countries, 1,600+ indicators, data from 1960. If a number about a country's economy exists, it is here.

**3. EIA International Data (eia.gov/international)**
U.S. government = public domain, completely free to use. The best source for energy data globally — oil production, consumption, reserves, electricity by country by year. Wendover used EIA for the Guyana table.

## How Wendover Found the Data for the Guyana Table

Working backwards from the table in the screenshot:

| Column | Source | How to find it |
|--------|--------|---------------|
| Oil Rents as % of GDP | World Bank | data.worldbank.org → "Oil rents (% of GDP)" |
| GDP per capita | World Bank | data.worldbank.org → "GDP per capita (current US$)" |
| Oil Reserves (millions of barrels) | EIA | eia.gov/international/data/world/petroleum-and-other-liquids/annual-crude-and-lease-condensate-reserves |
| Population | World Bank or UN | data.worldbank.org → "Population, total" |
| Oil Reserves Per Capita | Calculated | Reserves ÷ Population (not a pre-existing dataset — Wendover computed it) |

**The key insight:** The last column — Oil Reserves Per Capita — does not exist as a downloadable dataset anywhere. Wendover created it by dividing EIA reserves data by World Bank population data. This is editorial work, not data retrieval. The most powerful column in the table was built, not found.

**This is the evergreen data workflow:**
1. Find two or more public datasets
2. Join them on a common key (country name, year)
3. Compute a derived metric that tells a story no single dataset tells alone
4. That derived metric becomes the unique insight of your video

## How to Join Two Datasets — Step by Step

This is the most important practical skill in evergreen video production. The best insights come from combining two datasets that were never designed to be combined.

### The problem

World Bank calls a country "United States." EIA calls it "United States of America." UN calls it "United States of America (the)." When you try to match rows from two different datasets by country name, they will not align automatically.

### The solution — a standard country name list

Use ISO 3166-1 alpha-3 country codes as the join key. Every serious dataset includes them. Instead of matching "Germany" to "Germany, Federal Republic of," you match "DEU" to "DEU."

**Step 1:** Download both datasets as CSV  
**Step 2:** Open both in Excel or Google Sheets  
**Step 3:** Add a column "ISO3" to each file  
**Step 4:** Use a lookup table to convert country names to ISO3 codes  
**ISO3 lookup table:** datahub.io/core/country-list — free CC0 download  
**Step 5:** Use VLOOKUP or INDEX/MATCH to join the two files on the ISO3 column  
**Step 6:** Create your derived metric in a new column

### Example — recreating the Wendover Guyana table
**https://www.google.com/search?q=Wendover+Found+the+Data+for+the+Guyana+Table&oq=Wendover+Found+the+Data+for+the+Guyana+Table&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIHCAEQIRigATIHCAIQIRigAdIBBzU5NmowajeoAgCwAgA&sourceid=chrome&ie=UTF-8#fpstate=ive&vld=cid:1171f62b,vid:cQI9z7picQI,st:0

```

File 1: World Bank → Oil rents (% of GDP) by country by year
File 2: World Bank → GDP per capita by country by year  
File 3: EIA → Proved oil reserves by country
File 4: World Bank → Population by country

Join key: ISO3 country code

Filter: Keep only top 10 countries by oil reserves
Sort: By oil reserves descending
```

**Total time:** 45–90 minutes for someone comfortable with spreadsheets

### Common joining problems and solutions

| Problem | Cause | Solution |
|---------|-------|---------|
| Country names don't match | Different naming conventions | Use ISO3 as join key |
| Years don't align | Different reporting periods | Use the most recent year where both datasets have data |
| Missing values | Country not in one dataset | Mark as N/A — do not fill with zero |
| Different units | One in millions, one in billions | Check metadata carefully before calculating |
| Territorial disputes | Some countries not recognized by all bodies | Use UN member state list as canonical reference |

## How to Verify Source Reliability

Not all data is equally trustworthy. Before building a video on a dataset, verify these five things.

### 1. Who collected the data?

**Tier 1 — Highest trust:** UN agencies (WHO, ILO, UNHCR), World Bank, IMF, national statistical offices (Destatis, INSEE, ONS), EIA, NASA  
**Tier 2 — High trust:** Academic institutions (Oxford, Harvard), peer-reviewed research, central banks  
**Tier 3 — Use with caution:** NGO reports, think tank data, industry associations  
**Tier 4 — Verify independently:** News articles citing statistics, press releases, social media  

### 2. What is the methodology?

Every serious dataset has a methodology document. Look for:
- How was the data collected? (Survey, administrative records, satellite, estimation)
- What is the sample size or coverage?
- How are missing values handled?
- Has the methodology changed over time?

If there is no methodology document — the dataset is not production-ready for an evergreen video.

### 3. How often is it revised?

GDP data is revised multiple times after first publication. Initial estimates are often significantly different from final figures. For evergreen videos, use final/revised figures, not preliminary estimates.

**Check for:** "Preliminary," "Estimate," "Flash estimate" labels — these will change.

### 4. Do multiple independent sources agree?

If World Bank says country X had 5% GDP growth in 2019 and IMF says 4.8%, the data is robust — two independent methodologies produce similar results. If they differ by more than 10%, investigate why before using either figure.

### 5. Is the source cited by other credible sources?

If the New York Times, The Economist, or a peer-reviewed journal cites the dataset, it has passed editorial scrutiny. This is the fastest verification shortcut.

## Sources Not on the Internet — Academic & Archival

Some of the best evergreen data exists only in academic papers, historical archives, and institutional reports. These require a different search process.

### Free academic databases

**Google Scholar** (scholar.google.com)  
Search for papers on your topic. Many include supplemental data tables. Papers published before 2000 are often fully available free.

**Semantic Scholar** (semanticscholar.org)  
AI-powered academic search. Better than Google Scholar for finding relevant papers you would not think to search for directly.

**JSTOR** (jstor.org)  
3 free articles per month without registration. Full access free through many public libraries.

**arXiv** (arxiv.org)  
Preprints in economics, social science, statistics — fully free. Often contains cutting-edge data analysis before it appears in journals.

**SSRN** (ssrn.com)  
Social science preprints — economics, law, finance, political science. Mostly free.

### Central bank historical archives

Every major central bank publishes historical economic data that predates the World Bank and IMF:

- **Bundesbank:** German monetary data from 1948 — bundesbank.de/en/statistics
- **Bank of England:** UK data from 1694 — bankofengland.co.uk/statistics
- **Federal Reserve (FRED):** US data from 1776 in some series — fred.stlouisfed.org

### Finding historical data that has not been digitized

For pre-1950 data on obscure topics, the best sources are:
- **HathiTrust Digital Library** (hathitrust.org) — millions of digitized historical books and reports, free
- **Internet Archive** (archive.org) — historical government documents, statistical yearbooks
- **League of Nations Statistical Yearbooks** — available on archive.org, contain pre-WWII global data

## Visual Sources — Images, Maps, and Footage with Open Licenses

Evergreen videos need more than numbers. These sources provide images, maps, and footage that can be used freely.

### Maps and geographic images

**Natural Earth** (naturalearthdata.com) — CC0, vector map data for custom animations  
**OpenStreetMap** (openstreetmap.org) — CC BY-SA, detailed geographic data  
**NASA Earth Observatory** (earthobservatory.nasa.gov) — public domain, satellite images of Earth  
**USGS Earth Explorer** (earthexplorer.usgs.gov) — public domain, satellite and aerial imagery  
**Copernicus Open Access Hub** (scihub.copernicus.eu) — free, European satellite data  

### Historical and archival images

**Wikimedia Commons** (commons.wikimedia.org) — millions of images, most CC or public domain  
**Library of Congress** (loc.gov/pictures) — US historical photos, mostly public domain  
**Europeana** (europeana.eu) — European cultural heritage, many items CC or public domain  
**Getty Images Free** (gettyimages.com/editorial-images) — editorial use only, not for commercial video  

### Video footage

**Pexels** (pexels.com) — CC0 video clips, free for commercial use  
**Pixabay** (pixabay.com) — CC0 video and images  
**Videvo** (videvo.net) — mixed licenses, filter for "Free to use" only  
**Internet Archive** (archive.org/details/movies) — historical footage, mostly public domain  
**NASA Video Gallery** (images.nasa.gov) — public domain, space and Earth footage

## How to Monitor Data Updates Automatically

Evergreen videos need current data at the moment of production. These methods alert you when sources publish new figures — without checking manually.

### Method 1 — RSS feeds (no coding required)

World Bank, OECD, IMF, and EIA all publish RSS feeds of new data releases.

**World Bank RSS:** blogs.worldbank.org/opendata/rss.xml  
**IMF RSS:** imf.org/en/News/rss  
**EIA RSS:** eia.gov/rss/  
**Eurostat RSS:** ec.europa.eu/eurostat/web/rss  

Add these to any RSS reader (Feedly, Inoreader — both free) and you see new data releases in your feed daily.

### Method 2 — Google Alerts

Set up alerts for search terms like:
- "World Bank data release 2025"
- "EIA oil production statistics"
- "Eurostat GDP quarterly"

Google sends an email when new pages matching these terms appear.

### Method 3 — Dataset-specific notifications

**World Bank:** data.worldbank.org → any indicator → "Subscribe to updates" button  
**Our World in Data:** ourworldindata.org/subscribe — email newsletter when new datasets added  
**OECD:** oecd.org/newsroom/subscribe — press releases including data releases  

### Method 4 — Wikipedia as a proxy

For evergreen topics, Wikipedia's "Economy of X" pages are updated quickly when new official data is released. Monitor the Wikipedia page for your topic as a lightweight alert system — if the numbers changed, the source data has been updated.
