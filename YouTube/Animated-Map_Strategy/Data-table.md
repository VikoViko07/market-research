# Data Table
## Who Uses It, When, and Who Does It Best

---

## What Is a Data Table in Video Context

A data table in video is not a spreadsheet — it is a deliberate trust signal. It appears on screen for 4–8 seconds, shows multiple variables for multiple subjects simultaneously, and communicates one thing above all others: "this is real data, from real sources, you can verify it yourself."

The screenshot that prompted this analysis is from Wendover Productions' "The World's Fastest Growing Economy" (November 2024, 983K views). The table shows 10 oil-producing countries across five variables: Oil Rents as % of GDP, GDP per capita, Oil Reserves, Population, and Oil Reserves Per Capita.

That table is not there to be read. It is there to be felt.

---

## The Core Principle — Why Tables Work in Video

Charts simplify. Tables complicate — deliberately. When a viewer sees a table after a series of clean charts and animations, the cognitive shift is intentional:

> "I've been showing you the story. Now here is the raw material the story is built from."

This is why tables appear rarely in the best educational channels — typically once per video, if at all. Overuse destroys the effect. The table's power comes from its contrast with everything around it.

## Channel-by-Channel Analysis

### Wendover Productions — The Leader

**Frequency:** 1–2 tables per video, used selectively  
**Position:** Mid-video, after the context is established and before the key insight  
**Style:** Dark background `#1a2332`, no row dividers, alternating subtle row shading, flags as the only color  
**What makes it work:**

Wendover's table in the Guyana video shows five variables for ten countries. The viewer is not expected to read all fifty data points. The table is designed to reveal one anomaly through visual weight alone — Libya's 56.4% Oil Rents and Iraq's 42.8% stand out against the single-digit figures for Canada (2.8%) and the United States (0.6%) without any highlight, callout, or annotation. The data speaks because the design stays silent.

The source attribution is embedded in the column headers — "(World Bank)" and "(millions of barrels — EIA)" — not in a footnote. This is the European academic convention: the source is part of the label, not an afterthought.

**Wendover's table design specs (from screenshot):**

| Element | Value |
|---------|-------|
| Background | `#1a2332` — deep navy, not pure black |
| Row shading | Alternating `#1a2332` / `#1e2840` — barely visible |
| Country name | White, 14px, weight 500 |
| Numbers | `#cbd5e1`, 13px, weight 400 |
| Column headers | `#94a3b8`, 12–13px, weight 500, two lines |
| Source in header | `#64748b`, 10px, in parentheses below header text |
| Flag size | ~20×14px — the only color element |
| Row dividers | None |
| Column dividers | None |
| Max rows | 10–12 |
| Hold time | 4–6 seconds |

**When Wendover uses a table:**
- When comparing more than 4 variables across more than 6 subjects simultaneously
- When the data contains an outlier the viewer should discover themselves
- As a credibility anchor before a provocative claim
- Never at the start or end of a video — always mid-argument

### Our World in Data — The Academic Standard

**Frequency:** Tables used extensively — but primarily on their website, rarely in video format  
**Style:** White background, clean borders, interactive sorting  
**What makes it work:**

Our World in Data's tables are the reference standard for data credibility in educational content. They are cited by the New York Times, The Economist, BBC, and Nature. Their table design is the opposite of Wendover's: light background, visible grid, prominent source links.

For YouTube specifically, OWID avoids full tables in video — they show chart fragments instead. But their data tables are the source material that Wendover, Kurzgesagt, and Veritasium draw from when building their own table frames.

**OWID table design principles:**
- Source always hyperlinked, never just named
- Download button visible — transparency as design feature
- Column sorting enabled — viewer agency is part of the format
- White background — academic, not cinematic

**When OWID tables appear in video context:** Almost never. OWID is a data source, not a video producer. Their tables appear as screenshots in other channels' videos as a credibility reference.

---

### The Economist — The Print Standard Adapted for Screen

**Frequency:** Heavy use in print; selective in video/digital  
**Style:** White background, thin hairline borders, "Economist red" accent for key figures  
**What makes it work:**

The Economist has the most refined table design in journalism. Their tables use a single red accent color — `#E3120B` — applied only to the one number that carries the story. Every other number is black or gray. The table header uses a thin red underline, not a filled background. The result is a table that looks like a newspaper but reads like a chart.

For educational YouTube channels covering economics, The Economist's table style is the highest-trust reference point. A table that visually echoes The Economist signals serious research.

**Economist table design specs:**
| Element | Value |
|---------|-------|
| Background | White `#FFFFFF` |
| Header underline | `#E3120B`, 2px |
| Key figure accent | `#E3120B` — one cell or column only |
| Body text | `#1a1a1a`, 12–13px |
| Column headers | `#1a1a1a`, weight 700, uppercase |
| Row dividers | `#e5e7eb`, 0.5px |
| Source | "Source: [name]" below table, 10px italic |

### FiveThirtyEight — Data Journalism Tables

**Frequency:** Moderate — tables used alongside charts, not instead of them  
**Style:** Light gray background `#f0eff0`, bold headers, distinctive color accents per topic  
**What makes it work:**

FiveThirtyEight's tables are built around sortability and filtering — they are designed for readers who want to explore data, not just receive a conclusion. For video adaptation, this means their table style works best for "here is the full dataset" moments, not "here is one insight" moments.

Their tables use a light gray background that feels different from both the white academic standard (OWID, Economist) and the dark cinematic standard (Wendover). The result is a "newsroom" aesthetic — data that feels live and current.

**FiveThirtyEight for evergreen YouTube:** Their table style is harder to adapt to video because it implies interactivity. Static FiveThirtyEight-style tables in video look unfinished — like a screenshot of a tool rather than a designed visual.

---

### Johnny Harris — Minimal Reference Tables

**Frequency:** Rare — 1 table per 3–4 videos  
**Style:** Dark background, white text, very wide first column (country/subject name), bold key figure  
**What makes it work:**

Johnny Harris uses tables only when a claim is so specific that it requires documented evidence on screen. His table design is maximally spare: no borders, no shading, just aligned text on dark background. The effect is closer to a military briefing slide than a data visualization.

**When Johnny Harris uses a table:**
- When quoting a specific statistic from a government or international body document
- When showing treaty terms, budget allocations, or treaty text fragments
- When the source is a primary document that the viewer might want to verify

---

### Kurzgesagt — No Tables

**Frequency:** Never — by design  
**Why:**

Kurzgesagt has explicitly built their visual language around the principle that every data point can be illustrated. If a fact requires a table, they either convert it into an animated comparison, a card infographic, or they cut it from the script. A table in a Kurzgesagt video would break the visual contract with their audience — "we always show, never just tell."

**The implication for evergreen channels:** Kurzgesagt's choice is a valid production philosophy. Tables are not mandatory. If your channel commits to fully illustrated data, tables become a sign of production failure rather than credibility. The choice is stylistic, but it must be consistent.

---

### RealLifeLore — Occasional Geographic Tables

**Frequency:** Low — 1 per 4–5 videos  
**Style:** Dark background similar to Wendover, focus on geographic data (area, population, borders)  
**When used:** When comparing multiple countries' statistics to establish a geographic argument — similar to Wendover's approach but with more focus on size and territory data

## Who Is the Leader

**Wendover Productions is the clear leader** in data table usage for educational YouTube.

Three reasons:

**1. Strategic placement.** Wendover places tables after the emotional hook and before the key claim. The table arrives when the viewer is invested — not at the start when they have no context, not at the end when they have already drawn conclusions.

**2. Design restraint.** No grid lines, no color coding, no highlights. The anomalies reveal themselves through the numbers alone. This requires more editorial confidence than adding callouts and arrows — but creates a more lasting impression.

**3. Source integration.** The source is inside the column header, not below the table. This is a small decision with significant cognitive effect: the viewer never asks "where does this come from?" because the answer is already in frame.

## When to Use a Data Table — Decision Framework

```
Does the story require showing multiple variables
for multiple subjects simultaneously?
          │
         YES → Can this be shown as a chart?
                    │
                   YES → Use the chart. Tables are slower to read.
                    │
                    NO → Is there one anomaly the viewer should find themselves?
                              │
                             YES → Use a table. Design it to let the anomaly emerge naturally.
                              │
                              NO → Use card infographics (Format 16) instead.
```

**Use a data table when:**
- You have 4+ variables for 6+ subjects and no single chart type captures all of them
- You need to establish source credibility before a controversial claim
- The story contains an outlier that is more powerful when the viewer discovers it than when you point it out
- You are comparing countries, companies, or entities where the viewer might want to look up their own country

**Do not use a data table when:**
- One variable tells the whole story (use a bar chart)
- You have fewer than 4 rows (use card infographics)
- You have fewer than 3 columns (use a simple comparison)
- You are at the start or end of a video
- The story is about emotion, not evidence

## The One Rule That Separates Good Tables from Great Tables

> **The narrator names one number. The viewer finds the rest.**

In the Wendover Guyana table, the narrator likely says something like "Libya derives 56% of its entire economy from oil revenues." The viewer hears that, finds Libya in the table, confirms 56.4%, and then — without any prompting — scans the other numbers. Canada: 2.8%. UAE: 15.7%. Iraq: 42.8%.

The narrator did not say any of those numbers. The viewer discovered them. Discovery is remembered. Delivery is forgotten.

This is the fundamental principle of data table design for video: the table gives the viewer more information than the narrator provides, and trusts them to explore it.

## Evergreen vs. News Video — How the Table Changes

The same table design serves completely different purposes depending on whether the video is evergreen or news-driven. Wendover's Guyana table is a masterclass in evergreen table construction — and the choices are visible once you know what to look for.

### The core difference

| Dimension | News video table | Evergreen video table |
|-----------|-----------------|----------------------|
| Data horizon | Quarterly or annual figures | Structural data: reserves, ratios, per capita |
| Shelf life | 6–18 months | 5–10 years |
| Variable choice | Current numbers (GDP this year) | Structural ratios (oil rents as % of GDP) |
| Source type | Government press release, IMF update | World Bank, EIA, UN — slow-updating institutions |
| Risk | Looks outdated within 2 years | Remains valid as long as the structure holds |
| Design implication | Highlight the current number | Highlight the structural relationship |

### What Wendover chose — and why it works for 10 years

Every variable in the Guyana table was selected for structural stability:

**Oil Rents as % of GDP** — this ratio changes slowly. Libya was at 56% in 2022 and will still be structurally oil-dependent in 2032. The number may shift, but the story (extreme dependence) remains true.

**GDP per capita** — the relative ranking of these countries changes very slowly. Kuwait being wealthier than Iraq per capita is a structural fact, not a news event.

**Oil Reserves in millions of barrels** — reserve estimates update every few years, not every quarter. The order of magnitude is stable for decades.

**Population** — the slowest-changing variable of all. Saudi Arabia having 37 million people is a structural fact for at least 20 years.

**Oil Reserves Per Capita** — a derived ratio that is stable precisely because both inputs (reserves and population) are slow-changing.

**The editorial principle:** For evergreen tables, never use variables that update faster than once per year. Quarterly earnings, monthly trade figures, weekly polling data — all of these age the video. Structural ratios, per-capita figures, and cumulative totals are evergreen-safe.

### The 3-year problem — and how to solve it

All evergreen tables eventually face a credibility gap. Wendover's 2024 table will show slightly different numbers in 2027. Three strategies that evergreen channels use:

**Strategy 1 — Description update.** Pin a comment or update the video description: "Data updated: [date]. Original table used World Bank 2022 figures. Current figures available at [source link]." This acknowledges the passage of time without re-editing the video.

**Strategy 2 — Structural framing in the narration.** If the narrator says "as of 2024, Libya derives 56% of its GDP from oil" rather than "Libya derives 56%", the timestamp is embedded. Viewers know the figure is period-specific.

**Strategy 3 — Updated companion video.** Wendover and Johnny Harris both release "revisited" videos on their most successful evergreen topics. The original video stays live — it becomes historical context. The new video answers "what changed."

## Why Exactly 10 Rows — The Cognitive Science

The choice of 10 countries in the Guyana table is not arbitrary. It reflects a specific constraint: the maximum number of rows a viewer can scan on a mobile screen in 4–6 seconds.

### The mobile scan constraint

80% of YouTube traffic is mobile. On a standard phone screen (375px width), a 10-row table at 36–40px row height occupies roughly 360–400px of vertical space — almost exactly one screen length. The viewer does not need to scroll. The entire table is visible in one glance.

At 15 rows, the table extends beyond the phone screen. The viewer either misses the bottom rows or feels anxious about data they cannot see. At 6 rows, the table feels cherry-picked — the viewer wonders what was excluded.

**10 rows is the sweet spot:** comprehensive enough to feel authoritative, compact enough to read in one take.

### The 4-second scan pattern

Eye-tracking research on data tables shows a consistent pattern: viewers scan the first column (country names) top to bottom in approximately 1.5 seconds, then return to the row that caught their attention, then scan across that row's values.

This means: the first column must create a narrative. Wendover's country ordering is not alphabetical — it is ordered by Oil Reserves (largest first). This ordering ensures that the most resource-rich countries appear at the top, and the viewer naturally asks "then why are some of them poor?" before the narrator answers the question.

**The column ordering principle for evergreen tables:**
- Sort by the variable that establishes the context, not the variable that delivers the conclusion
- Put the "punchline" variable in the last column — the viewer reaches it after building expectation
- Never sort alphabetically — it destroys the narrative arc

## The Five Variables — Why These Specifically

The five columns Wendover chose tell a complete story about the resource curse without a single word of explanation. This is editorial architecture, not data selection.

### Column 1: Oil Rents as % of GDP (World Bank)

This is the dependency ratio. A high number means the economy has not diversified — it lives or dies with the oil price. Libya at 56.4% and Iraq at 42.8% immediately signal fragility. Canada at 2.8% and the US at 0.6% signal resilience through diversification.

**Why this column first:** It answers the structural question before the viewer has formed an opinion. They see the ratio and immediately understand what the video is really about — not wealth, but vulnerability.

### Column 2: GDP per capita

This is the wealth check. After seeing the dependency ratio, the viewer expects high-dependency countries to be poor. Then they see Kuwait ($83,902 per capita, 27.6% oil rents) and UAE ($83,902, 15.7%) — wealthy and oil-dependent simultaneously. The expected correlation breaks, and the viewer needs to understand why.

**Why this column second:** It introduces the complexity. Simple story → complication → resolution. The table structure mirrors the narrative arc.

### Column 3: Oil Reserves (millions of barrels, EIA)

This is the future claim. Countries with large reserves have a different strategic position than countries where reserves are declining. Venezuela's 304,000 million barrels next to Canada's 170,000 million immediately raises the question: Venezuela has more oil — why is its GDP per capita ($17,402) so much lower than Canada's ($61,582)?

**Why this column third:** It sets up the comparison that the narration will resolve. The viewer is now holding a question the table created.

### Column 4: Population

This is the scale normalizer. Saudi Arabia's 37 million people versus the US's 346 million changes the entire interpretation of reserve size. A country with enormous reserves and a small population — Kuwait with 5 million people — has a completely different resource endowment per citizen than a country with the same reserves and a large population.

**Why this column fourth:** It prepares the final column by providing the denominator.

### Column 5: Oil Reserves Per Capita (barrels)

This is the punchline. Kuwait: 20,400 barrels per person. UAE: 12,555. US: 213. The last column delivers the conclusion the entire table was building toward: per-capita endowment, not absolute reserves, determines what oil wealth means for individual citizens.

**Why this column last:** The viewer has earned it. They have scanned four columns of context. The fifth column lands with the force of a conclusion because the preceding four created the question.

## Typography Hierarchy as Narrative Tool

The color choices in Wendover's table — white for country names, light gray for numbers — are not aesthetic decisions. They are reading-order instructions.

### The hierarchy

**White (`#f1f5f9`) — country names:** White is the highest-contrast element against the dark background. The eye goes there first. This is intentional: the viewer should orient by geography before processing numbers. "I am looking at Saudi Arabia" before "I am looking at 23.7%."

**Light gray (`#cbd5e1`) — data values:** Slightly lower contrast than white. The eye reaches here second, after the geographic anchor is set. The viewer processes the number in the context of the country they have already identified.

**Darker gray (`#94a3b8`) — column headers:** Lower contrast still. Headers are reference labels — the viewer reads them once to understand the columns, then ignores them while scanning rows. Low contrast reflects low frequency of attention.

**Muted gray (`#64748b`) — source attribution:** The least visually prominent element. Sources are for credibility — they should be visible without demanding attention. A viewer who doubts the data will seek out the source label. A viewer who trusts the data will never consciously notice it.

### The flags as anchor

The flags are the only color elements in the table. Color creates salience — the eye finds color before text. This means every row scan begins with the flag, which triggers the country name, which anchors the number.

Without flags, the table is a wall of text. With flags, it is a geographic argument where each row is a country making its case.

**The design rule:** In dark-background data tables, one and only one non-data element should carry color. That element should be the geographic or categorical identifier — the thing that tells the viewer "here is where this data belongs."

## Summary — The Evergreen Data Table Checklist

Before including a data table in an evergreen video, verify:

- [ ] All variables update slower than once per year
- [ ] The row count is 10 or fewer
- [ ] The column count is 6 or fewer
- [ ] Rows are sorted by the context variable, not alphabetically
- [ ] The "punchline" variable is in the last column
- [ ] One non-data element carries color (flag, icon, or category marker)
- [ ] Source attribution is embedded in the column header, not in a footnote
- [ ] The narrator names exactly one number — not the whole table
- [ ] The table will be on screen for 4–8 seconds maximum
- [ ] The anomaly (the outlier that proves the argument) is discoverable without annotation
